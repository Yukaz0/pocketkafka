# Coding & Style Rules

1. **Minimal Code Comments**:
   - Jangan menambahkan terlalu banyak comment (`//`) di code.
   - Jika tidak benar-benar krusial/penting (self-explanatory code), **tidak perlu ada comment sama sekali**.
   - Hindari comment yang hanya mengulangi apa yang sudah jelas dari nama variabel atau function.
   - Pertahankan comment yang mendokumentasikan spesifikasi protokol, security invariants, atau alasan non-obvious.

2. **Clean & Concise Implementation**:
   - Utamakan code yang bersih, ekspresif, dan mudah dibaca tanpa perlu banyak penjelasan inline.

3. **Cleanup File Test Setelah Pengetesan**:
   - Setelah pengetesan atau verifikasi selesai, file test sementara / file test yang dibuat harus dihapus jika sudah selesai digunakan.
